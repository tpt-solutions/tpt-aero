## [Unreleased]

### Added
- `examples/` folder with a wing, rotor and aircraft case file generated by `template`.
- `tpt-aero wing case.toml`: alpha sweep to CSV (`alpha_deg,cl,cdi,cm,cl_roll,cn,lift_n`).
- `tpt-aero derivatives case.toml --alpha`: stability derivatives, with `--json`.
- `tpt-aero vtk case.toml --alpha`: legacy ASCII VTK of the lattice with circulation.
- `tpt-aero rotor rotor.toml`: one BEMT operating point, with `--json`.
- `tpt-aero trim aircraft.toml --speed`: level trim, with `--altitude`, `--bank` for a coordinated turn, and `--json`.
- `tpt-aero template wing|rotor|aircraft`: commented starting case files.
- `tpt-aero isa <alt>...`: standard atmosphere table.
- `-o` / `--out FILE` on every command.
- Case files reject unknown or misspelled keys.
- Work limits: ISA 0 to 84 852 m, sweep points capped at 10 000, mesh counts at 500, and surfaces at 2 500 panels.
