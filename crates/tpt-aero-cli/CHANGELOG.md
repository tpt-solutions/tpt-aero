# Changelog

All notable changes to `tpt-aero-cli` are documented here. Workspace-wide
notes are in the root [CHANGELOG.md](../../CHANGELOG.md).

Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Versioning: [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- `wing --mesh-sweep N,N,...`: C_L and C_Di at each spanwise strip count, as `n_span,cl,cdi` CSV. Needs an explicit `mesh.n_span` in the case; conflicts with `--check-mesh`, `--svg` and `--spanwise`.
- `trim --csv`: the trim report as `quantity,value,unit` rows.
- `rotor --collective-sweep START:STOP:STEP` (degrees) and `rotor --speed-sweep START:STOP:STEP` (m/s, with an advance-ratio column `J = π λ_c`).
- `wing --spanwise DEG`: spanwise strip loading at one angle.
- `trim --speed-sweep START:STOP:STEP` (m/s): level trim per speed as CSV. `--speed` is now required only without a sweep.
- Rotor cases accept `chord_profile` and `twist_profile_deg`: one value per station, hub side to tip, overriding the linear taper and twist.

### Changed
- The trim text report has a units column. Numbers are unchanged; `cases/aircraft.trim-50ms.expected.txt` is regenerated to the new layout.
- Sweep errors name the flag that caused them.

### Added
- `examples/` folder with a wing, rotor and aircraft case file generated by `template`.
- `tpt-aero wing case.toml`: alpha sweep to CSV (`alpha_deg,cl,cdi,cm,cl_roll,cn,lift_n`).
- `tpt-aero derivatives case.toml --alpha`: stability derivatives, with `--json`.
- `tpt-aero vtk case.toml --alpha`: legacy ASCII VTK of the lattice with circulation.
- `tpt-aero rotor rotor.toml`: one BEMT operating point, with `--json`.
- `tpt-aero trim aircraft.toml --speed`: level trim, with `--altitude`, `--bank` for a coordinated turn, and `--json`.
- `tpt-aero template wing|rotor|aircraft`: commented starting case files.
- `tpt-aero isa <alt>...`: standard atmosphere table.
- `-o` / `--out FILE` on every command.
- Case files reject unknown or misspelled keys.
- Work limits: ISA 0 to 84 852 m, sweep points capped at 10 000, mesh counts at 500, and surfaces at 2 500 panels.

### Fixed
- Initial release candidate; no fixes recorded against this crate yet.
