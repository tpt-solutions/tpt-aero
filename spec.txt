tpt-aero Design Specification (spec.txt)
1. Overview
Name: tpt-aero
Description: A pure-Rust, AI-native specialized aerodynamics and flight mechanics library. It provides fast, analytical, and semi-empirical aerodynamic solvers (VLM, Panel Methods, BEMT), atmospheric modeling, and stability derivative extraction without C/C++ FFI or external solver dependencies.
License: MIT (all dependencies must be MIT or compatible; no Apache-2.0-only crates).
Core Philosophy: Unit-safe, no_std + alloc compatible at the core, differentiable for aerodynamic shape optimization, and mathematically rigorous via native Rust verification tooling and from-scratch implementations.
2. Design Principles
Zero External Solver Dependencies: No X-Plane FFI, no AVL (Athena Vortex Lattice) bindings, no external linear solvers. All aerodynamic influence coefficient (AIC) matrix assemblies and linear solves are implemented from scratch in pure Rust, leveraging tpt-math.
Strict Licensing: No Apache-2.0-only dependencies. The workspace strictly uses MIT, MIT/Apache-2.0 dual, or custom in-house crates.

4. Crate Specifications
tpt-aero-core
Purpose: The foundational layer. Defines aerodynamic geometry, airfoil polars, and non-dimensional physics.
Dependencies: tpt-math (internal, MIT).
Key Features:
Unit-safe wrappers for Dynamic Pressure (

Airfoil polar interpolation (Cl/Cd/Cm vs Alpha/Mach/Re) with stall modeling.
Geometry primitives: Lifting line panels, quadrilateral surface panels, and airfoil coordinate transformations.
no_std + alloc compatible.
tpt-aero-vlm
Purpose: Fast 3D aerodynamic analysis for wings, tails, and lifting surfaces.
Key Features:
From-scratch Vortex Lattice Method (VLM) using horseshoe vortex lattices.
Aerodynamic Influence Coefficient (AIC) matrix assembly and native LU/Cholesky solve.
Modeling of camber, twist (washout), and dihedral.
Differentiable AIC assembly for gradient-based wing shape optimization (e.g., minimizing induced drag via twist distribution).
tpt-aero-panel
Purpose: Higher-fidelity 3D aerodynamics for complex fuselage and nacelle geometries.
Key Features:
Panel methods using source and doublet distributions.
Slender body theory for rapid fuselage aerodynamics.
Compressibility corrections (Prandtl-Glauert, Karman-Tsien) for subsonic/transonic regimes.
tpt-aero-rotor
Purpose: Aerodynamics of rotating machinery (propellers, rotors, turbines).
Key Features:
Blade Element Momentum Theory (BEMT) with iterative induction factor solving.
Tip loss models (Prandtl, Glauert) and hub loss corrections.
Skewed wake and dynamic inflow models for helicopter/VTAM UAV rotors.
Propeller performance mapping (thrust, power, efficiency vs. advance ratio).
tpt-aero-atmo
Purpose: Environmental and atmospheric modeling for flight simulation.
Key Features:
International Standard Atmosphere (ISA) model (density, temperature, pressure, speed of sound vs. altitude).
Wind shear and gust models (1-cos, sharp-edge).
Continuous turbulence models (Dryden, von Kármán) for flight dynamics simulation.

5. Integration & Synergies
tpt-flight-control / tpt-multibody-dynamics: tpt-aero-stability provides the linearized aerodynamic plant matrices. tpt-aero-atmo provides the environmental disturbances. Together, they feed the 6-DOF equations of motion.
tpt-physics (CFD): tpt-aero acts as the fast, low-fidelity surrogate in the design loop. tpt-physics is reserved for high-fidelity, high-angle-of-attack, or separated flow regimes where VLM/Panel methods fail.
tpt-systems-optimisation: The differentiable VLM and BEMT implementations allow tpt-systems-optimisation to perform gradient-based multidisciplinary design optimization (MDO) of aircraft or wind turbine blades.
tpt-fem-modal: Enables aeroelastic coupling (flutter analysis) by combining tpt-aero unsteady aerodynamics with tpt-fem structural mode shapes.
